# Learning Notes

这个目录记录 `llm-inference-delivery-lab` 的制作过程、踩坑、解决方案、脚本解释和基础知识科普。

它和 `docs/` 的区别：

- `docs/`：对外展示的正式工程文档。
- `learning/`：面向学习和复盘，记录为什么这样做、遇到什么问题、如何解决。

## 文件说明

| 文件 | 作用 |
|---|---|
| `build-log.md` | 项目制作过程和阶段复盘 |
| `issues-and-fixes.md` | 报错、根因、解决方案 |
| `scripts-explained.md` | 脚本、命令、配置解释 |
| `basics/inference-serving.md` | 推理服务基础 |
| `basics/benchmarking.md` | 压测指标基础 |
| `basics/docker-compose.md` | Docker Compose 基础 |
| `basics/python-project.md` | Python 项目工程基础 |

## 使用方式

每完成一个阶段，把过程中的关键问题记录到这里：

```text
问题现象
→ 根因
→ 解决方案
→ 学到的工程原则
```
